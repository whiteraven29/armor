## Contributing to Armor

- Thank you for your interest in contributing! We appreciate your help to make this project better.
## Quick Rules 
- Search existing issues and pull requests before opening a new one.
- Open an issue to discuss major changes before you start writing code.
  
## How to Contribute
1. Fork the repository and create your branch from main
2. Make your changes (fix bugs or add features).
3. Run tests or checks locally to make sure everything works
4. Commit your changes using clear messages (for example: `fix: fix a typo in README)`.
5. Push your branch and open a pull request against main.
   
   
## Code of Conduct
- Please treat everyone with respect and follow our community standards.
